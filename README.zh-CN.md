## 你好，我是 Lipeng 👋

我关注**计算生物学与生物信息学**，希望理解细胞和免疫受体组库如何随着发育、衰老与疾病发生变化。这里的项目围绕单细胞分析、T 细胞生物学和实用科研软件展开。

我日常使用 **R、Python 和 Linux** 分析测序数据、组织工作流程，也喜欢把生物学发现画成清楚易读的图。分享有用的代码、学习新方法，以及把反复遇到的研究任务整理成顺手的工具，都是我持续投入的事。
